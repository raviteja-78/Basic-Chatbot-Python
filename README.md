Basic Chatbot Using Python

Project Description

This project is a simple rule-based chatbot developed using Python. It interacts with users and provides predefined responses based on their input.

Features

- Greets users with Hello.
- Responds to How are you?
- Says Goodbye when the user types Bye.
- Handles unknown messages.

Technologies Used

- Python
- Google Colab

How to Run

1. Open the Python notebook.
2. Run the code.
3. Enter a message.
4. Chat with the bot.

Output

The chatbot successfully responds to user messages.
